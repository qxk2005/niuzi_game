# 牛子的游戏库

小小创意，大大冒险。14 个基于原生 HTML、CSS 和 Canvas 的网页小游戏，支持手机、平板和电脑。

## 运行

无需构建，也无需安装游戏依赖。克隆后在仓库根目录启动静态服务：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000`。同一 Wi-Fi 下，手机和平板可通过电脑的局域网 IP 访问。

## 玩法和触控

- 大厅可以搜索、分类和收藏游戏；收藏和最近游玩记录保存在本机浏览器。
- 每款游戏都有玩法帮助。游戏大厅提供暂停、继续、重开、返回和全屏；浏览器不支持全屏时仍可使用整屏游戏视图。
- 战斗游戏采用“点卡片，再点场景”，卡片栏可左右滑动。无需鼠标拖拽。
- 森林救援支持左手摇杆、右手攻击；手势取消、切后台或暂停时释放移动输入。
- 暗房游戏按住并滑动手指移动；汉堡游戏按住土豆滑动削皮。
- 手机竖屏可以游玩，横屏有更宽的战场。游戏画布和 HTML 操作区分别适配，旋转时保留逻辑画布坐标。
- 暂停冻结动画、游戏计时器和已播放的合成音效。关闭游戏会卸载 iframe，结束该游戏的运行。

## 代码结构

- `index.html`：游戏大厅和 iframe 播放器。
- `assets/games.js`：游戏目录、简介与入口。
- `assets/lobby.css`、`assets/lobby.js`：大厅外观、搜索、收藏和播放器生命周期。
- `assets/game-ui.css`：按游戏分别配置的响应式布局、触控尺寸和安全区。
- `assets/game-ui.js`：坐标转换、游戏帮助、导航、暂停、输入释放及 60 Hz 调度。
- 根目录编号 HTML：每款游戏的绘制、规则、关卡和独立状态。

所有游戏不依赖外部字体或资源服务。各游戏的进度存档能力不同；大厅收藏不代表自动保存游戏关卡。

## 检查

运行游戏不需要 Node。开发验证使用 Node 22+：

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

`npm test` 检查脚本语法、资源、入口，以及 60/90/120/144 Hz 调度与暂停计时。浏览器检查覆盖 320、390、844、768、1024、1366 像素宽度，以及 14 款游戏的嵌入播放器、触摸种植、乐高拼装、汉堡完整制作、削皮、摇杆、暂停和旋转。截图和检查记录保存在 `test-results/`，不会提交进仓库。

已有 Chromium 时可通过 `NIUZI_CHROMIUM_EXECUTABLE` 指定可执行文件。浏览器自动化模拟触屏不等同于真实 iOS Safari、iPadOS 和 Android 的完整验收。

## 部署

GitHub Pages 使用 `.github/workflows/static.yml`，推送 `main` 后部署。`.github/workflows/check.yml` 在 PR 和主分支运行基础与浏览器检查。

新增游戏时，在 `assets/games.js` 加入目录数据，并为页面加载共用 UI 文件、设置 `data-game` 编号。涉及画布尺寸时，交互坐标使用 `GameUI.point(canvas, event)`；动画和计时器使用 `GameUI` 调度接口，确保暂停时不会继续推进游戏。
